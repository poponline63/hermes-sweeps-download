# hermes-sweeps-download

Free download page for Hermes Sweeps, a Windows desktop app that collects daily sweepstakes
casino bonuses on your own accounts.

This repository exists for one reason: to host the installer so the download link never changes.

## Download

Grab the newest build from the [releases page](../../releases/latest).

The installer asset keeps a fixed name on purpose, so the public link stays valid across versions.

## What the app does

It signs in to the sweepstakes casinos you already have accounts with, claims each site's daily
bonus, and reports what it found. You supply your own logins. Nothing is shared with anyone, and
there is no account to create.

## Requirements

Windows 10 or 11. The app keeps itself updated from its own release feed.
